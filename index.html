Wi-Fi пульт для ресивера на основе ESP32

Веб-пульт и аппаратный контроллер для беспроводного управления домашним кинотеатром по локальной сети.

  • Управление питанием, громкостью, выбором треков и приводом с любого устройства по Wi-Fi из любой комнаты без зоны прямой видимости
  • Трансляция команд ресиверу по инфракрасному протоколу Philips RC-6 через транзисторный передатчик
  • Физическая кнопка на корпусе для управления без смартфона: переключение режимов звука и запуск случайного трека по двойному клику
